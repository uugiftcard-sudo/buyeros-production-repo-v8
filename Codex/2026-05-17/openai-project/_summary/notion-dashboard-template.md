## Suggested Database: AI Conversations

Recommended properties:

| Property | Type | Purpose |
| --- | --- | --- |
| Title | Title | Conversation name |
| Platform | Select | ChatGPT, Claude, Gemini, Perplexity, Telegram, Other |
| Project | Multi-select | Related project name |
| Date | Date | Conversation date |
| Status | Select | Inbox, Reviewing, Active, Important, Archived |
| Priority | Select | Low, Medium, High |
| Tags | Multi-select | coding, research, prompt, planning, personal, work |
| Summary | Text | Short human summary |
| Key Decisions | Text | Major decisions or outcomes |
| Next Actions | Text | Follow-up tasks |
| Source Link | URL | Original conversation link |
| Raw File | Text | Local export file path |
| Reusable Prompt | Text | Prompt worth saving |
| Notes | Text | Anything extra |

## Weekly Workflow

1. Import new files into the local organizer.
2. Add new rows into the AI Conversations database.
3. Tag project, platform, and importance.
4. Write one short summary per conversation.
5. Save strong prompts into the prompt library.
6. Archive low-value items.
